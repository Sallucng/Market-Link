Google OAuth 2.0 Implementation & Windows SSL Fix
Operational

1. Root Cause Analysis of cURL Error 60

When clicking "Continue with Google", Windows PHP threw the following exception in storage/logs/laravel.log:

local.ERROR: Google OAuth callback failed: cURL error 60: SSL certificate OpenSSL verify result: unable to get local issuer certificate (20) for https://www.googleapis.com/oauth2/v4/token

This happens because standard Windows PHP binaries do not bundle an OpenSSL Certificate Authority file. When Guzzle attempted to verify Google's token endpoint over HTTPS, the verification failed.

2. Permanent System Fix Applied

  1. Downloaded Mozilla's official root CA bundle (cacert.pem, 188 KB) into PHP's directory.
  2. Configured php.ini with:
    curl.cainfo = "C:\Users\User\AppData\Local\Microsoft\WinGet\Packages\PHP.PHP.8.3_Microsoft.Winget.Source_8wekyb3d8bbwe\cacert.pem" openssl.cafile = "C:\Users\User\AppData\Local\Microsoft\WinGet\Packages\PHP.PHP.8.3_Microsoft.Winget.Source_8wekyb3d8bbwe\cacert.pem"
  3. Added Guzzle fallback verification in config/services.php for local development environments.
  4. Successfully tested secure HTTPS handshake to Google APIs with HTTP 200/404 verified.

3. Strict Security Policies Enforced

Strict Admin Blockade

Admin accounts are strictly forbidden from signing in via Google OAuth. Any attempt by an administrative email displays a security error and redirects to the username/password login.

"Option 1" Profile Completion

New users signing in with Google are routed to the /auth/google/complete-profile gate to provide their contact phone number, physical address, and stall name (if Farmer).

Farmer Approval Gate

Customer accounts are instantly active. Farmer accounts created with Google are set to is_approved = false until approved by platform administrators in the Admin portal.

Platform Functional Modules & SRS Deliverables

Zero-Fee Stall Pre-Orders

Customers build their harvest basket throughout the week. Orders lock inventory in real time. Payment is completed in person at the stall via Cash or Card terminal, eliminating costly payment processor transaction fees for small local farmers.

2-Hour Order Cutoff Engine

To protect growers from rush orders during morning harvesting, the platform automatically halts pre-orders 2 hours prior to market opening. Farmers can customize their cutoff duration in their profile dashboard.

OpenStreetMap Geolocation

Integrated Leaflet mapping interface displaying verified weekend market locations. Calculates distance from community shoppers and filters stalls by active market days.

AI Produce Assistant (Gemini)

Floating AI chat assistant powered by Gemini 2.5 Flash with contextual grounding across live database products, seasonal produce tips, and order guidance.

Multi-Language Localization

One-click language switcher supporting English (LTR), Spanish (LTR), and Urdu (RTL) with complete bidirectional styling and mirrored layout transformations.

Admin Governance & Approvals

Comprehensive administrator backoffice for approving new farmer stall applications, deactivating abusive accounts, resolving dispute complaints, and platform auditing.
